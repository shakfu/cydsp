## cydsp is now nanodsp

This package has been renamed. Use `pip install nanodsp` instead.

New package: <https://pypi.org/project/nanodsp>

New repo: <https://github.com/shakfu/nanodsp>

Note that installing this [package](https://pypi.org/project/cydsp/0.1.3.post0/
) (which was renamed at `v0.1.3.post0`) will always install `nanosynth==0.1.3`. Development will continue in the nanosynth project.
